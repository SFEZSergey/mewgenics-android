# Mewgenics-android

An Android (arm64) port of Mewgenics (PS5, PPSA37318) built on AnyPS5, box64, and Turnip.
Tested on Snapdragon 8 Elite (Adreno 830), reaching 60 FPS in combat.

Game data must not be stored in this repository. Users import their own game dump.
AnyPS5 is GPL-2.0-only; its source code is published with the port.

## How it works

```
app.elf (x86-64, game) ──box64──▶ SDL_GPU game frontend (x86)
                                      │ SDL_GPUDevice slots = box64 bridges
                                      ▼
                      libaps5sdlgpu.so (arm64): SDL3 Vulkan backend + shim
                                      ▼
                          Turnip (Mesa, libvulkan_freedreno.so)
```

* The game renders through SDL3 SDL_GPU. The only backend in `app.elf` is the PS5 `Agc` backend.
  box64 (`aps5hot.c`) replaces its `CreateDevice` function (loader pointer at
  `0x1a6e468`, code hash `0xfb170c2bbebbdcf3`) with SDL3's native Vulkan backend.
  If native initialization fails, the game stays on Agc (the AnyPS5 path: AGC → PM4 → Vulkan).
* Shaders: the game supplies PSSL, and the backend substitutes SPIR-V using the blob's FNV-1a hash
  (`<game>/sdlgpu/<hash>.spv`, generated by `tools/mew-sdlgpu-shaders.sh`).
* PS5/Vulkan differences handled by `android/sdlgpu/backend.c`:
  - Compressed texture uploads can have unaligned offsets (4 modulo 16); data is copied to an
    aligned buffer. This is the main cause of texture artifacts.
  - New textures are zero-initialized, matching PS5's zeroed memory.
  - `bitmap_atlas_info` (an R32_FLOAT 9100x1 table) is copied to a storage buffer and bound
    automatically because the game does not bind it.
  - `cycle` is disabled for GPU records; `DONT_CARE` becomes `LOAD/STORE`.
  - Letterboxing: the game renders to a 1920x1080 canvas, which is scaled and centered on screen.
* SDL bug fix: `Download*` lacked a `TRANSFER_WRITE → HOST_READ` barrier, so the CPU read zeros on
  Turnip. This is patched during the build by `android/sdlgpu/patch_sdl.py`.

## Contents

| Path | Description |
|---|---|
| `AnyPS5/` | Emulator source with patches from `patches/anyps5-*.patch` applied |
| `mesa/` | Mesa 26.3 (Turnip) with `patches/mesa-26.3-android.patch` |
| `android/sdlgpu/` | Native Vulkan SDL_GPU backend (C); built with `build.sh` |
| `android/apk-build.sh` | APK build script (copied from `~/ps5-android/apk/build.sh`) |
| `patches/` | AnyPS5, Mesa, and box64 patches (`box64-local.patch`) |
| `tools/` | Build, installation, and diagnostic scripts; see `TOOLS.md` |
